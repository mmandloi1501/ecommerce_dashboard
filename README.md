## 📌 The Business Problem

E-commerce businesses generate enormous volumes of sales and customer data — but without the right analytics tools, this data sits unused. Business leaders need instant visibility into:

- Which products and regions are driving revenue?
- Which customers are most valuable and at risk of churning?
- How are sales trending over time?

**This dashboard answers all of these questions in real time** — giving business analysts and managers the insights they need to make faster, smarter decisions.

## 💡 Key Business Insights Delivered

- **Sales trend analysis** — identifies peak periods and seasonal patterns to inform stock and staffing decisions
- **Top product ranking** — highlights best sellers so marketing budget can be focused on high performing lines
- **Geographic revenue breakdown** — shows which markets generate the most value and where growth opportunities exist
- **RFM Segmentation** — classifies customers into Champions, Loyal, At Risk, and Lost segments enabling targeted retention campaigns

---

## 🔍 What is RFM Analysis?

RFM stands for **Recency, Frequency and Monetary** value — a proven customer segmentation technique used by leading retailers worldwide.

| Dimension | Question it answers |
|-----------|-------------------|
| Recency | How recently did this customer buy? |
| Frequency | How often do they buy? |
| Monetary | How much do they spend? |

Customers are scored on each dimension and grouped into segments — allowing businesses to target their most valuable customers and re-engage those at risk of churning.

## 🚀 How to Run Locally

**Step 1 — Clone the repository**
```bash
git clone https://github.com/mmandloi1501/ecommerce-dashboard.git
cd ecommerce-dashboard
```

**Step 2 — Install dependencies**
```bash
pip install -r requirements.txt
```

**Step 3 — Run the dashboard**
```bash
streamlit run app/dashboard.py
```
